# Privacy Policy for GirlsinSight

**Effective date:** April 17, 2026

## Overview

GirlsinSight is a Chrome extension for analyzing comment threads on GirlsChannel.net. This privacy policy explains what data the extension accesses, how it uses that data, how it stores that data, and when that data is shared.

## Data the extension accesses

When a user intentionally runs GirlsinSight on a GirlsChannel.net topic page, the extension accesses content from that page. This may include thread titles, comment text, visible comment metadata, page URLs, and related page content needed for sentiment analysis and summarization.

The extension also stores user-provided settings, including the user’s Google Gemini API key, language settings, and analysis preferences.

GirlsinSight does not collect unrelated browsing history, does not monitor activity on pages the user has not chosen to analyze, and does not collect financial information, health information, or location information.

## How the data is used

GirlsinSight uses the accessed GirlsChannel.net page content to perform sentiment analysis, generate summaries, and present results to the user inside the extension interface.

The stored Gemini API key is used only to authenticate requests to Google’s Gemini API so that the extension can analyze the selected page content.

## How the data is stored

User settings, including the Gemini API key and analysis preferences, are stored in Chrome storage used by the extension, including Chrome sync storage where applicable.

GirlsinSight does not operate its own backend server for storing user data.

## How the data is shared

When the user runs an analysis, relevant page content may be sent to Google’s Gemini API for processing. This is necessary for the extension’s core functionality.

Other than sending data to Google’s Gemini API for the requested analysis, GirlsinSight does not sell user data, does not transfer user data to data brokers, and does not share user data with third parties for advertising or unrelated purposes.

## Data retention

Stored settings remain in the extension’s storage until the user changes them, clears the extension data, or uninstalls the extension.

GirlsinSight does not retain analyzed page content on a developer-operated server after processing.

## User control

Users can stop all processing by not running the extension. Users can remove stored settings by clearing extension storage or uninstalling the extension.
